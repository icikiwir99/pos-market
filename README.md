# POS Indowowok - Aplikasi Kasir & Inventaris Indomaret (Laravel)

Aplikasi Point of Sale (POS) Kasir, Pengelolaan Inventaris Gudang, dan Dashboard Analitik Manager berbasis Laravel.

## 🔗 Live Demo (HTTPS)
* **URL:** https://pos-indomaret.onrender.com *(ganti dengan link deploy kamu)*

---

## 🔑 Informasi Akun Login Testing

Silakan gunakan akun di bawah ini untuk menguji hak akses masing-masing role:

| Role | Email / Username | Password | Deskripsi Fitur Utama |
| :--- | :--- | :--- | :--- |
| **Kasir** | `kasir@indomaret.com` | `password123` | Scan/Input barang, Checkout transaksi, Cetak Struk |
| **Gudang** | `gudang@indomaret.com` | `password123` | Barang masuk, Update stok, Stock adjustment |
| **Manager** | `manager@indomaret.com` | `password123` | Dashboard omset, Laporan penjualan/stok, Master data user |

## 🛠️ Tech Stack & Modul Utama
* **Framework:** Laravel 10 / 11
* **Database:** MySQL Cloud (Aiven)
* **Architecture:** Role-Based Access Control (RBAC)
